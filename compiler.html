使用说明

      
    
        
  • 随机数 / 时间：8 位 LCG（周期 256），rand 每调用一次都会推进种子，所以循环里连续取随机数不会重复。
            srand / srandom 设种子，rand / random 返回 0–255，
            randint(a,b) / uniform(a,b) 取闭区间，randbool() 返回 0/1。
            <ctime> 的 time / clock 因无系统时钟固定返回 0，
            所以 srand(time(nullptr)) 等价于 srand(0)，每次运行的第一局答案固定；
            想让第一局也可变，改成「先 cin >> n 再 srand(n)」。
            编译器还会启用 输入熵：程序每读到一次输入就扰动随机种子，之后每局、以及输入序列不同时数字都不同。
            <random> 的 std::mt19937、uniform_int_distribution 等引擎/分布
            对象语法不支持（BF 没有对象与模板），请改用上面的函数式写法。
    • 
        
  • 位运算：& | ^ ~ << >> 及对应复合赋值全部支持（8 位无符号）。
            << / >> 的位移量是常量时直接生成乘除，代码很短；& | ^ ~
            与变量位移量由内部函数逐位实现，单次约 1 万条指令。混合运算建议加括号。
    • 
        
  • 预处理：#define NAME 值 支持常量宏（可嵌套引用）；内置
            true false NULL RAND_MAX CHAR_MAX UCHAR_MAX INT_MAX EOF。
            库函数按源码里实际调用自动启用，不写 #include 也能用；未收录的头文件会给出提示。
    • 
        
  • 命名空间：std::rand()、std::abs()、std::min() 等会自动剥掉
            std::；std::cout / cin / endl 照常可用。
    • 
        
  • 数值语义：所有变量是一字节无符号（0–255 回绕）。abs / sqrt / pow / gcd 是 8 位整数版；
            time() 没有系统时钟，固定返回 0。toupper / tolower 返回字符，
            max / isdigit / randint 等返回数字 —— 这会影响 cout << 按字符还是按十进制输出。
    • 
        
  • std::string：用 1 格长度 + 32 格字节模拟，按 UTF-8 字节存放，
            所以 length() / size() 返回的是字节数（一个汉字算 3 个）。
            支持声明 / 赋值 / 拷贝 / + 拼接 / += / length / size / empty / clear /
            push_back / pop_back / append / at / substr / find / s[i] 读写 /
            六种字典序比较 / cout << s / printf("%s") /
            cin >> s（读到空白，分隔符回推）/ getline / to_string / stoi。
            超出 32 字节会被截断并告警；字符串不能作函数参数 / 返回值，请改用全局字符串变量。
    • 
        
  • 数组：int a[5] / int m[3][4] 等任意维数、任意元素类型
            （char / int / int32_t / double / string）。每个元素在编译期摊成独立单元格：
            常量下标直接命中、零开销；变量下标生成逐维比较的选择树，代价 O(元素数)。
            长度必须是编译期常量；元素很多（几十上百）时代码会明显变长。
            变长数组、把数组当函数参数传递不支持（指针本身可用，见下一条）。
    • 
        
  • return：函数体里任意位置都能提前返回 —— 循环体内（含多层嵌套，
            会一路跳出所有外层循环）、if / else 分支内、do-while 内都支持。
            main 里的 return 等于「程序到此结束」，后续语句一条都不会执行。
            void 函数可写 return;，非 void 函数必须带返回值。
            BrainFuck 没有跳转指令，实现方式是「继续执行标志」：return 把标志清零，
            之后所有语句包一层 if (标志)、循环条件变成 标志 && 原条件，
            于是自然退出。只有真的出现多处 return 才会加这层开销；唯一的 return 位于末尾时直接省掉。
    • 
        
  • 标准函数：类型名可以直接当函数用（char(65) / int(x) / double(2) /
            bool(x) / string("hi")），语义与 C 风格强转一致；std:: 前缀自动剥离。
            <cctype> 全套字符分类与 toupper / tolower 可用，
            strlen 支持字面量 / std::string / char 数组，
            atoi / stoi / atol / strtol 字面量会在编译期算完。
            floor / ceil / round / trunc 按「放大 1000 倍的定点数」正确取整；
            fabs / labs / llabs 按 8 位绝对值处理。
    • 
        
  • 指针：BrainFuck 没有地址，指针在编译期绑定到「目标变量名」——
            int *p = &a; 之后 *p 直接就是 a，不占单元格、零额外指令。
            支持取地址 &a / &a[i]、解引用读写（含 += -= *= /= ++ --）、
            重新绑定 p = &b、数组名退化 int *p = a、
            指针下标 p[i] 与偏移 *(p+1)。
            指向数组的指针做 p++ / p-- / p += n 时会自动生成一个运行期游标格，
            *p 走数组选择树（代价 O(元素数)）—— 因此数组遍历能正确随 p++ 移动。
            void f(int* p) 指针形参复用引用内联机制，*p 在调用点落到实参那一格。
            scanf("%d", p) / cin >> *p 可用。
            指针真假与相等（if (p) / p == nullptr / p == q）编译期判定。
            边界：** / void* / 函数指针 / new / 任意地址算术 不支持；
            char *s = "hi" 按 std::string 降级并告警。
    • 
        
  • 边界：<vector> <map> <set> 等容器头文件只识别、不支持；
            模板、树状递归同样不在子集内。class / struct 按「成员变量→全局变量、
            方法→普通函数」降级（单对象等价）；64 位整数取低 8 位，chrono / 系统时钟固定为 0，
            cin 流状态按「读取成功」处理，这些都会逐条给出告警。
